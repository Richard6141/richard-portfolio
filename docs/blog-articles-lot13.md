<h2>Indicateur 1 : le LCP (vitesse de chargement)</h2>
<p>Le <strong>Largest Contentful Paint</strong> mesure le temps avant que l'élément principal de la page s'affiche. En clair : à quelle vitesse votre contenu apparaît. Objectif : moins de 2,5 secondes.</p>
<p><em>Correctifs :</em> compresser les images, utiliser un bon hébergeur, activer le cache, alléger le code.</p>

<h2>Indicateur 2 : l'INP (réactivité)</h2>
<p>L'<strong>Interaction to Next Paint</strong> mesure la rapidité avec laquelle le site répond quand on clique ou qu'on tape. Un site qui « rame » au moindre clic frustre immédiatement.</p>
<p><em>Correctifs :</em> réduire les scripts lourds, limiter le JavaScript inutile, optimiser le code.</p>

<h2>Indicateur 3 : le CLS (stabilité visuelle)</h2>
<p>Le <strong>Cumulative Layout Shift</strong> mesure si les éléments « sautent » pendant le chargement. Vous avez déjà cliqué au mauvais endroit parce que la page a bougé ? C'est un mauvais CLS.</p>
<p><em>Correctifs :</em> réserver l'espace des images et publicités, éviter les insertions qui décalent le contenu.</p>

<div class="art-callout">
  <b>Comment mesurer ?</b> Lancez un test gratuit sur <a href="https://pagespeed.web.dev/" target="_blank" rel="noopener">PageSpeed Insights</a> ou suivez le rapport « Signaux web essentiels » dans <a href="https://search.google.com/search-console/about" target="_blank" rel="noopener">Search Console</a>. Visez le vert sur mobile en priorité.
</div>
